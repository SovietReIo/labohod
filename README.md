# Лабоход

Переодевалка «Лиги Героев» и расчёт процента побед по каждому мобу этажа лабиринта.
Одна страница, весь движок и бестиарий внутри. Сервера нет, ничего никуда не отправляется.

## Как выложить на GitHub Pages

1. Заведи аккаунт на github.com, если его нет.
2. Создай репозиторий: **New repository** → имя `labohod` → **Public** → **Create**.
3. На странице репозитория: **Add file → Upload files**. Перетащи туда **всё содержимое этой папки** (не саму папку — именно файлы внутри). **Commit changes**.
4. **Settings → Pages** → в блоке *Build and deployment* источник **Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
5. Через минуту-две адрес появится там же вверху страницы Pages:
   `https://ТВОЙ-НИК.github.io/labohod/`

Ссылка для фокус-группы — она. Одностраничник «что проверять» лежит рядом:
`https://ТВОЙ-НИК.github.io/labohod/brief.html`

## Как обновить

**Add file → Upload files**, перетащи новый `index.html` и `sw.js`, **Commit**. У всех обновится при следующем открытии.

`sw.js` обязательно вместе с `index.html` — в нём номер версии, по которому сбрасывается кеш.

## Как поставить на телефон

- **Android / Chrome** — зайти по ссылке, меню ⋮ → «Установить приложение».
- **iPhone / Safari** — зайти по ссылке, «Поделиться» → «На экран „Домой“».

После установки открывается без адресной строки и работает без интернета.

## Что внутри

| файл | зачем |
|---|---|
| `index.html` | весь сервис: движок, 349 мобов, вещи, зелья, последователи |
| `brief.html` | одностраничник для фокус-группы |
| `manifest.webmanifest` | имя, иконка и режим приложения |
| `sw.js` | офлайн-кеш, версия сбрасывается при каждой сборке |
| `icon-*.png` | иконки |
| `.nojekyll` | чтобы GitHub отдавал файлы как есть |

## Источники данных

Бестиарий и отряды мобов — flhelper.ru. Вещи, зелья, последователи и правила боя — энциклопедия «Лиги Героев».
